Quest APK Renamer for Linux x86_64
==================================

Install:

  1. Extract the downloaded .tar.gz file.
  2. Open a terminal in this folder.
  3. Run: ./install.sh
  4. Open Quest APK Renamer from your app launcher.

You can also run "Quest APK Renamer" directly without installing it.

The bundle includes Python, Java, keytool, ADB, Apktool, the APK signer, and
drag-and-drop support. No administrator access is required.

To uninstall, run ./uninstall.sh from the extracted download or installed app
folder. Signing keys and settings are intentionally preserved.

Use only with APK/OBB bundles you own or are authorized to modify.
