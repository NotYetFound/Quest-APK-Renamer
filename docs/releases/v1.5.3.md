# Quest APK Renamer 1.5.3

This update makes Library easier to browse and helps keep game updates complete.

- **Library search:** Filter installed apps by name or original/renamed package ID.
- **Compact layout:** Smaller rows, click-to-select, fewer repeated labels, and
  side-by-side update buttons.
- **Consistent scrolling:** Library uses the same wheel and touchpad handling as Settings.
- **Complete managed updates:** Recognized OBBs are included when rebuilding a managed
  app, even if the general OBB-copy setting is off.
- **Clearer update checks:** See the APK/OBB count before proceeding. A build stops with
  an explanation if APK analysis would discard previously discovered, mismatched OBBs.
- **New default tag:** New installations suggest `.mr` for compatibility with
  Quest Game Optimizer. Existing saved preferences stay unchanged.

Thanks to [gleniu87](https://github.com/gleniu87) for the game-specific fixes
([#39](https://github.com/NotYetFound/Quest-APK-Renamer/pull/39)) and `.mr` default
([#40](https://github.com/NotYetFound/Quest-APK-Renamer/pull/40)).
