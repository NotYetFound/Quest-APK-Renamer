# Quest APK Renamer 1.5.0

Games that keep required files alongside their `.obb` files now retain that data when building a
renamed copy and installing it on the Quest.

## Complete game data

- Copies non-OBB files from the game's recognized package folder into the renamed bundle,
  preserving nested folders. Files outside that folder are excluded.
- Installs those files into the matching package folder on the headset.
- Includes the extra data in capacity estimates and the build report.

## Transfers and retry

- Extra files have their own transfer stage and progress display.
- Files already matching on the Quest are skipped after size and SHA-256 checks.
- Changed files upload under temporary names and are verified before activation.
- Retry handles pending OBBs and extra files without reinstalling an already-installed APK or
  resending successful transfers. The retry button describes the remaining work.
- Failed or cancelled transfers retain the source and clean up their temporary uploads.
  Source deletion happens only after the complete installation succeeds.
- Symlinks are skipped locally, unsafe paths are rejected, and linked Quest destinations are
  refused. Unrelated files already on the headset are preserved.
