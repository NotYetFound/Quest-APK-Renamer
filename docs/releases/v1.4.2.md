# Quest APK Renamer 1.4.2

This focused dashboard update makes older-firmware patch compatibility and
long-running work easier to understand without adding extra setup steps.

## Highlights

- Enable the older-firmware patch preference at any time. The app remembers the
  choice and only applies it when the selected APK contains the compatible ARM64
  `libovrplatformloader.so` file.
- See a small compatibility indicator beside the selected source: a green check
  when OFP can be used and a muted X when it cannot. Hover the indicator for the
  full explanation.
- Follow richer live progress with the current operation, target, exact
  percentage, OFP stage, and byte-level APK/OBB copy details.
- Updated the application icon so its rename arrows sit higher and closer to the
  visual center.

No source is patched when its compatible loader is absent, even when the OFP
preference is enabled.
