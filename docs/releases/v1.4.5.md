# Quest APK Renamer 1.4.5

Version 1.4.5 makes headset updates and signing-key recovery safer, improves OBB compatibility,
and hardens the app and release packages across platforms.

## Library and updates

- **Live headset first:** The Library now opens on the connected Quest's current third-party apps
  and automatically returns to that view when a headset reconnects.
- **Usable key vault:** Saved identities can be selected, copied, opened, exported individually,
  removed from automatic matching, or exported/imported as a complete list.
- **Portable private backups:** `.qarlib` archives contain the full saved profile, signing key,
  key metadata, and cached icon. Paths, size limits, and SHA-256 hashes are checked before import.
- **Safer recovery:** Removing a vault entry keeps its private key files on disk, and corrupt
  settings or Library JSON is preserved with a last-known-good backup.

## OBB and install reliability

- Numeric and Unreal-style `pakchunk` OBB tags are preserved while only the package portion is
  renamed. Ambiguous, mismatched, unsupported, and colliding files are rejected before output.
- Exact APK selection performs a package-aware second OBB search after analysis learns the real
  package ID.
- Quest updates reuse identical data, stage changed OBBs under transaction names, verify the APK
  and expected files, then remove only obsolete package-matching or previously managed files.
- A failed verification restores the prior OBB set or retains uniquely named recovery copies.

## Cross-platform and performance work

- The updater now uses the current public `NotYetFound/Quest-APK-Renamer` release channel.
- Release actions, Python build inputs, Temurin, and Android Platform Tools are pinned and verified.
- External build, inspection, signing, and ADB commands have bounded timeouts and process cleanup.
- Headset inventory uses bulk package-manager queries, large reference scans use bounded-memory
  streaming, and unchanged local OBB hashes are reused safely across retries.
- Linux packages are smaller while retaining native/Qt picker fallbacks, Wayland/X11 support, and
  the Qt image/rendering plugins used by the interface.

Use the tool only with APK/OBB bundles you own or are authorized to modify. A `.qarlib` archive and
copied vault information contain private signing credentials; store and share them accordingly.
