# Quest APK Renamer 1.4.6

Version 1.4.6 is a correctness, speed, and quality-of-life release driven by a full review of the
app: the installer no longer touches OBBs it did not bring, package renaming is exact, the
interface is faster and friendlier, and the headset can be reached over Wi-Fi.

## Headset connection

- **Wireless ADB:** connect by address (or a pasted `adb connect` line), or press **Enable over
  USB** once to switch a cabled Quest to Wi-Fi ADB and remember it. Saved Quests appear in the new
  connection panel and in Settings with rename, connect, disconnect, copy, and forget actions.
- **Device picker:** when several devices are attached, choose the Quest from the header chip; the
  choice is remembered. A lone Quest next to a phone is selected automatically.
- **Friendlier install failures:** `INSTALL_FAILED_*` codes are explained in plain language, and a
  signing conflict offers to uninstall the existing app and install again.

## Safer installs and exact renames

- An APK-only install (for example a patch sideload or a finished folder without OBBs) no longer
  deletes the OBB files already on the Quest for that package.
- Retrying failed OBB transfers no longer removes the other OBBs of the same game, and a transfer
  that failed before the APK was installed reruns the whole install.
- Package references are matched as whole tokens: renaming `com.example.game` no longer corrupts
  `com.example.gamepad` or `Lcom/example/gamepad/…;`. The Inspector preview uses the same rule.
- Version code, version name, and SDK levels are read from `apktool.yml` when recent Apktool
  releases strip them from the decoded manifest.
- Stale staging files on the headset are cleaned up, output folders get normal permissions,
  `release.manifest` records the real folder name, and tool errors show the real Java diagnostic.

## Faster, calmer interface

- Shared UI components, content-sized panels, consistent margins, tooltips, Enter-to-confirm in
  dialogs, remembered window size/page/folders, Open/Copy/Clear actions on the Dashboard,
  per-row Open/Copy-error in the bulk queue, Up/Down selection in the Library, a configurable
  default ID tag, and a Logs window that follows the tail.
- The device poll no longer overwrites results on the Dashboard; a symlinked APK no longer wedges
  analysis; unexpected worker errors never leave the app busy.
- Progress ticks no longer re-hash the signing key, log bursts are coalesced, the Library list is
  not rebuilt on selection, the installer lists and hashes remote OBBs with far fewer ADB round
  trips and shows transfer speed/ETA, startup hashes bundled tools once, and reference scanning,
  hashing, and signing verification are faster.

Use the tool only with APK/OBB bundles you own or are authorized to modify. A `.qarlib` archive and
copied vault information contain private signing credentials; store and share them accordingly.
