# Quest APK Renamer 1.4.7

Bug-fix release.

## Fixed

- Renamed copies of apps with their own native code (JNI) crashed at launch. Only the
  application ID is rewritten now; Java class names stay unchanged.
- Bundles with a tag-less `patch.<package>.obb` were rejected as unsupported.
- Several install problems on the headset: cancelling during cleanup could delete the verified
  OBB, retrying a failed multi-OBB install restored only one file, cancelling mid-activation left
  the original parked, large OBBs over wireless ADB timed out.
- Device detection mistakes (ADB server messages read as a device, underscore product codes,
  stale device state after picking a device or connecting wirelessly).
- Legacy signing-key migration and key-backup restore no longer lose app icons or imported
  identities.
- Assorted controller fixes: failed direct updates can be retried, the elapsed timer stops, the
  update checker re-arms, pasted paths with quotes or `file://` work, bulk queue no longer stops
  on a bad output folder.

## Added

- Optional, off-by-default display name for renamed copies (Settings, experimental).
- Legacy "also rename Java packages" mode, refused automatically when native code needs the
  classes.
- Confirmation before quitting while work is running.

## Changed

- Darker, cooler colour palette and contrast fixes.
- Reference scanning about 30x faster on large games.

Use the tool only with APK/OBB bundles you own or are authorized to modify.
