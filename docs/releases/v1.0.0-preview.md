# Quest APK Renamer 1.0.0 preview

Quest APK Renamer 1.0.0 is the first packaged Windows preview of the
beginner-friendly Quest APK/OBB rename and installation workflow.

## Highlights

- Select or drag in a complete game folder.
- Detect and change the technical Android package ID.
- Rebuild, sign, and verify a renamed APK.
- Rename matching OBB files and update `release.manifest`.
- See connected Quest status and available headset storage.
- Run preflight checks before building or installing.
- Install APK and OBB files together and verify the result.
- Retry only failed OBB transfers.
- Cancel safely between stages and clean partial output.
- Back up the persistent local signing key used for future updates.

## Downloads

- **Setup EXE** — recommended Windows installation with Start Menu integration.
- **Portable ZIP** — unpack and run without installation.
- **SHA256SUMS.txt** — integrity hashes for both Windows downloads.

The Windows packages include Java, Android SDK Platform-Tools, Apktool, Uber APK
Signer, and native drag-and-drop support.

## Important notes

- These Windows builds are not code-signed. SmartScreen may report
  **Unknown publisher**.
- Use the tool only with software you own or are authorized to modify.
- The app does not bypass store ownership, licensing, online entitlement, or
  anti-tamper systems.
- Package renaming may not work for games that check their original package ID
  or signing certificate in native, encrypted, or server-side code.
- Back up the generated `.jks` file and `signing-key.json` together before
  relying on a renamed package.

This version should remain marked as a prerelease until its exact uploaded
installer has completed the real-Windows and real-Quest smoke-test checklist in
`docs/RELEASING.md`.
