# Quest APK Renamer 1.5.2

This update makes it easier to follow your first rename and recover
when a build or install needs attention.

- **Optional guided tutorial:** Walk through choosing a source, changing the app ID,
  building a copy, and installing it to a connected Quest. Replay it from Settings.
- **Smoother Settings scrolling:** Wheel and touchpad input moves the page directly.
- **More responsive Dashboard:** Source discovery and readiness checks run in the background.
- **Provider authority conflicts:** Resolve leftover package ID placeholders in provider
  authorities so renamed copies can install beside the original. Thanks to
  [abdazez01](https://github.com/abdazez01) for [PR #38](https://github.com/NotYetFound/Quest-APK-Renamer/pull/38).
- **Output folder conflicts:** Choose whether to cancel, replace the existing output,
  or keep it and build into a numbered copy. The previous output stays in place until the
  replacement is ready, and source replacement refuses folders with unrelated files.
- **Build verification:** Signed APKs are explicitly verified before publication. The release
  manifest now lists extra game data, and free-space checks exclude files set to be skipped.
- **Easier feedback:** Operation errors offer a bug-report shortcut. After two successful
  renames, a one-time thank-you offers links to star the repo or open an issue.
- **Less disk work:** Bundle scanning avoids redundant directory lookups and rescans.
  The finished APK checksum is calculated during the output copy.
- **Desktop integration:** The app no longer passes its Qt Quick style to other
  desktop applications when opening files or folders.
