Quest APK Renamer — Linux x86_64

Run "Quest APK Renamer" directly for portable use, or run install.sh to add it to your
desktop application launcher. uninstall.sh removes only the application; settings, logs, and
signing keys remain under your normal XDG data directory.

The AppImage release is the simplest portable option: make it executable and open it. On Linux
systems without FUSE support, launch it with --appimage-extract-and-run.
